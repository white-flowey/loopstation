# Drumloop Station

Drum-Looper im Stil einer RC-505 – läuft als Offline-App (PWA) auf dem iPad.

**Installieren:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“ → einmal mit Internet starten.
Updates kommen automatisch beim nächsten Start der App (wenn Internet da ist).

## Songskizze

Songwriting-Skizzenbuch (Akkord-Loops, Drums, Gesang → Melodie, Notenblatt) unter [`/songskizze/`](https://white-flowey.github.io/loopstation/songskizze/). Eigene Web-App mit eigenem Offline-Cache, auf dem Homescreen separat installierbar.
